Sistema de design da Garage.

Não é um catálogo de enfeites. São as decisões que já foram tomadas, para que não sejam tomadas de novo a cada página. Quem for construir uma peça nova — site, deck, infográfico, post — começa por aqui.

Linha de visibilidade assinatura do sistema
01

Quatro princípios.

Toda decisão de componente ou de peça nova é resolvida por um destes quatro. Se nenhum resolve, é caso de estender o sistema, não de improvisar.

Escuro é o chãoO escuro é a superfície padrão — home, aberturas, capas, cabeçalho e rodapé. O claro é a mesa de leitura: corpo de case, corpo de artigo, formulário. Proporção de referência: ~80% escuro. Nunca usar claro só para "variar".
Cor tem funçãoVioleta é Criativa, âmbar é Hub, tijolo é matéria. Cor não distingue itens de uma mesma família — cinco situações do Hub recebem um marcador só, porque são cinco instâncias da mesma coisa. Se quatro coisas do mesmo tipo precisam de quatro cores, o problema é de hierarquia, não de paleta.
Hierarquia por pesoA ordem de leitura é construída por família e peso tipográfico, não por cor. Isso é o que impede a página de virar carnaval com três marcas na mesma tela.
Movimento revelaO movimento existe para mostrar estrutura — uma linha que se traça, uma raia que preenche, um número que conta. Nunca para chamar atenção. Uma direção, uma curva, uma vez só.
02

Cor.

As duas marcas puras (#8278FF e #FFAA32) são acento, não superfície: branco sobre elas reprova em contraste. Para superfície com texto branco existem as versões aprofundadas.

--char#17110EChão. Carvão com tijolo dentro, não preto neutro.
--char-up#221A15Superfície elevada: cards, blocos, painéis.
--cri#8278FFGarage Criativa. Só acento: régua, rótulo, borda.
--cri-deep#6C60EE · 4,62:1Superfície Criativa. Aceita texto branco.
--hub#FFAA32Garage Hub. Só acento. Branco em cima reprova (1,9:1).
--hub-deep / --brick#9C5233 · 5,72:1Superfície Hub e cor da matéria. Aceita texto branco.
--bone#D8CCC2Marcador neutro, quando itens são da mesma família.
--paper#F5F1EDMesa de leitura. Corpo de case, artigo, formulário.

texto secundário no escuro #A2938A  ·  lede #D8CCC2  ·  piso de contraste 4,5:1 em qualquer texto abaixo de 24px

04

Movimento.

O vocabulário de movimento é o de quem desenha um blueprint: linha que se traça, raia que preenche, número que conta. Nada flutua, nada quica, nada gira.

TokenValorOnde
--mo-in520msEntrada de qualquer elemento na viewport.
--mo-ui180msResposta de interface: hover, foco, cabeçalho.
--mo-line900msTraço de linha e barra de crepúsculo.
--mo-easecubic-bezier(.2,.7,.2,1)Curva única do sistema. Não existe segunda.
--mo-shift14px, de baixo para cimaDireção única. Duas direções viram ruído.
--mo-step65ms, teto de 8 itensEscalonamento entre irmãos do mesmo container.
Uma vez sóElemento que entra é desobservado. Reanimar ao rolar de volta cansa e faz a página parecer instável.
ProibidoEscala, rotação, quique, paralaxe, flutuação contínua, carrossel automático. É linguagem de portfólio de motion, não de consultoria.
DegradaçãoSob prefers-reduced-motion: reduce ou sem JavaScript, tudo nasce visível. O movimento é camada, nunca condição de leitura.
MarcaçãoZero atributo de animação no HTML. O motion.js etiqueta por seletor. Peça nova entra no sistema adicionando um seletor, não editando markup.

06

Dívida aberta do sistema.

O que está documentado como pendência não é falha — é decisão que ainda não foi tomada. O que não está documentado, sim.

Marca do Hub

O cabeçalho do Hub usa lockup tipográfico provisório porque o SVG não existe. Enquanto isso, a página do Hub não pode assinar como Garage Criativa.

Depende de asset

Campos comerciais

Carga horária, formato e número de encontros existem. Investimento, próxima turma e certificação não. Sem eles o comprador não pré-qualifica.

Depende de decisão

Endpoint de formulário

Os dois formulários validam e abrem o cliente de e-mail. É solução provisória: a captura real precisa de endpoint com registro.
